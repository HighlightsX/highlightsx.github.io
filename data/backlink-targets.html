Verify anything yourself

The method behind every row. If the output contains nofollow, sponsored, or ugc, the link passes nothing.

curl -s -A "Mozilla/5.0" "https://PLATFORM/YOUR-PROFILE" \
  | grep -oiE '<a [^>]*href="https?://[^"]*"[^>]*>' \
  | grep -i "YOURDOMAIN"

For client-rendered rows, open the page in a browser and run in DevTools console:

[...document.querySelectorAll('a[href*="YOURDOMAIN"]')]
  .map(a => a.rel || '(none = dofollow)')
