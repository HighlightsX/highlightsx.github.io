# Backlink candidates

Sweep run 17 Aug 2026 for https://highlightsx.github.io. Aggregated **923 candidate domains** from
directory-of-directory lists, awesome-lists and SEO round-ups, probed **279 of them live**, and kept the
**194 that are alive and plausibly relevant**. Everything already submitted lives in
[submissions.md](submissions.md) and is excluded here.

Every `rel` below was read out of live markup on the date above — never recalled. The rule: a link passes
equity unless the `rel` contains `nofollow`, `sponsored` or `ugc`. `noopener`, `noreferrer`, `me` and
`external` are **not** crawl directives and pass full equity.

Counts: **72 dofollow**, 17 nofollow,
102 unresolved (client-rendered or blocked), 3 avoid.

The filterable version of this table is [backlink-targets.html](backlink-targets.html) — open it in a browser.

## Two things that change how you use this list

**The submitsaas clone network.** Around two dozen rows here — acidtools, appalist, ashlist, beamtools,
besttoolvault, huntfortools, launchscroll, mylaunchstash, mystarttools, productlistdir, solvertools,
sourcedir, stackdirectory, startupaideas, theapptools, thecoretools, thekeytools, themegatools, tinytoolhub,
toolcosmos, toolfinddir, toolslisthq, toolsunderradar, unitelist, weliketools — are one operator running one
template, right down to the same `submitsaas.com` ad slot in the same position. Their listing links do pass
equity, but two listings from one operator is the practical ceiling before the profile reads as a pattern
rather than a set of independent mentions. Pick two, skip the rest.

**`*.github.io` still costs you rows.** BetaList already rejected the site for it. Several directories in the
unresolved block gate on a custom domain or a DR floor, which a fresh github.io cannot clear. A custom domain
unlocks that tier in one move.
